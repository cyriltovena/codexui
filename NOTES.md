# Notes

Scratch pad for dev notes, ideas, and reminders.

## General

- This repo powers the `codexapp` npm package — a browser-accessible UI bridge for Codex app-server workflows.
- Default port: `18923`
- Supports Linux, Windows, and Termux (Android).
